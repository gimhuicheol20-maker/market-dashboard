홈 화면 앱 · 푸시 알림

앱으로 쓰기

이 사이트를 휴대폰 홈 화면에 추가하면 앱처럼 열리고, 미장 AI·국장 AI 판정이 나오면 알림이 와요.

1. 홈 화면에 추가

확인 중…
  1. Safari로 이 페이지를 열어요. (다른 브라우저에서는 알림이 안 돼요)
  2. 아래쪽 공유 버튼 → 홈 화면에 추가를 눌러요.
  3. 홈 화면의 시스템 트레이딩 아이콘으로 다시 열고, 이 페이지의 2번에서 알림을 켜요.

아이폰은 iOS 16.4 이상, 홈 화면에 추가한 앱에서만 알림을 받을 수 있어요.

Chrome 메뉴(⋮) → 앱 설치 또는 홈 화면에 추가를 눌러요. 아래 버튼이 보이면 바로 설치할 수 있어요.

2. 알림 켜기

확인 중…

받는 알림: 미장 AI 감사 신호(아침 6:30)와 판정(밤 9시), 국장 신호(저녁 7시)와 재료 판정(아침 7시), 비상 손절 발동.

3. 자동 알림과 연결 (운영자용)

알림을 켜면 아래에 이 기기의 구독 정보가 나와요. 서버 없이 GitHub Actions가 직접 보내기 때문에, 이 정보를 저장소 Secret에 한 번 넣어 줘야 해요.

  1. 복사를 눌러요.
  2. GitHub 저장소 market-code → Settings → Secrets and variables → Actions에서 PUSH_SUBSCRIPTIONS를 만들고 붙여 넣어요.
  3. 기기가 여러 대면 한 줄에 하나씩 이어 붙여요.
  4. Actions → 앱 푸시 시험 → Run workflow로 확인해요.
